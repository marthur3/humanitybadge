## Detailed Description

**Prove You're Human - Not AI, Not Copy-Paste**

Humanity Badge is the easiest way to verify that your writing is authentically human-typed. Perfect for Reddit debates, LinkedIn thought leadership, and anywhere credibility matters.

### 🎯 How It Works

1. **Click the green ✓ button** that appears on any website
2. **Type normally** in any text field (paste is blocked to ensure authenticity)
3. **Get verified** - Automatic validation of your typing speed and rhythm
4. **Share proof** - Get a shareable replay link showing your authentic typing

### ✨ Key Features

**✅ Humanity Badge Certification**
- Cryptographic proof of authentic human typing
- Real-time WPM (Words Per Minute) calculation
- Visual verification badge
- Shareable typing replay links

**🛡️ Comprehensive Anti-Paste Protection**
- Blocks Ctrl+V, Cmd+V, right-click paste
- Prevents drag-and-drop text insertion
- Ensures 100% authentic typing
- Visual feedback when paste is attempted

**📱 Platform-Specific Sharing**
- **Reddit**: Pre-formatted markdown with verification badge
- **LinkedIn**: Professional verification text
- **Universal**: Works on any website with text input

**🔗 Professional URLs**
- Optional GitHub Gist integration for short URLs
- Standalone HTML export (works without extension)
- Multiple sharing options (is.gd shortener, direct links)

**🌐 Universal Compatibility**
- Works on ALL websites automatically
- Single fixed button (bottom-right corner)
- Detects textareas, contenteditable, and input fields
- No configuration needed

### 📊 Verification Criteria

**Authentic Typing Requirements:**
- Minimum duration: 5 seconds
- Realistic WPM: 10-200 words per minute
- No paste events during recording
- Natural human typing rhythm

**What Gets Verified:**
- Typing speed consistency
- Keystroke timing patterns
- Text composition over time

### 🎬 How Replays Work

When you share a verification link, recipients can:
- Watch keystroke-by-keystroke replay
- See your natural typing rhythm
- View verification metrics (WPM, duration, characters)
- Verify authenticity without installing extension

Replays are impossible to fake - timing signatures are unique to human typing.
